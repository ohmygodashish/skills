# Core Concept Deconstruction

## What it does

`core-concept-deconstruction` deconstruct highly complex, confusing, or jargon-heavy content by identifying its core foundation, explaining it through an everyday analogy, and validating comprehension via strict gatekeeping questions.

## When to reach for it

You invoke this by typing `/core-concept-deconstruction`.

| Your situation | What `core-concept-deconstruction` gives back |
| --- | --- |
| Facing dense, jargon-heavy technical documentation or theory | Isolates the single linchpin sentence and explains it using a grounded everyday analogy |
| Verifying true understanding vs superficial memorization | Deploy 3-question diagnostic gatekeeper to validate comprehension before proceeding |
