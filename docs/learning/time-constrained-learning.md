# Time-Constrained Learning

## What it does

`time-constrained-learning` accelerate the user's practical competence in a new skill within an arbitrary timeframe. Instruct the system to drop theoretical bloat, identify immediate high-value actions, and weed out time-wasting sub-topics.

## When to reach for it

You invoke this by typing `/time-constrained-learning`.

| Your situation | What `time-constrained-learning` gives back |
| --- | --- |
| Tight deadline to become functional in a new skill | Fast-track learning plan stripping theoretical bloat and focusing on high-value actions |
| Avoiding time-wasting sub-topics | Targeted practical execution plan to reach immediate competence |
