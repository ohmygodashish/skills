# Create Specification

## What it does

`create-specification` create a new specification file for the solution, optimized for Generative AI consumption.

## When to reach for it

You invoke this by typing `/create-specification`.

| Your situation | What `create-specification` gives back |
| --- | --- |
| Starting a new feature, architecture, or system component | Structured, machine-readable specification in `/spec/spec-[purpose].md` with acceptance criteria |
| Preparing requirements for Generative AI consumption | Clear AI-ready spec with explicit constraints, interfaces, and test strategies |
