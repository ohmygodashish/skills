# Presentation Speaker

## What it does

`presentation-speaker` custom writing style: Presentation Speaker. Apply only when the user explicitly requests this skill by its exact name 'presentation-speaker-style'. Rewrites text to sound like a live spoken presentation: signposting language, short punchy sentences, rhetorical questions, strategic repetition, a strong opening hook, and a memorable closing takeaway.

## When to reach for it

You invoke this by typing `/presentation-speaker`.

| Your situation | What `presentation-speaker` gives back |
| --- | --- |
| Converting written text into spoken presentation style | Spoken-friendly rewrite with opening hooks, signposting language, rhetorical questions, and closing takeaways |
| Preparing talk tracks, keynotes, or oral presentations | Varied sentence rhythm, emphatic repetition, and listener-oriented cadence |
